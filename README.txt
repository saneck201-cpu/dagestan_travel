Файлы проекта:
- index.html — весь сайт (HTML, CSS и JavaScript уже внутри файла).

Как опубликовать через GitHub Pages:
1. Открой github.com и войди в аккаунт.
2. Нажми + вверху справа -> New repository.
3. Назови репозиторий dagestan-travel. Можно выбрать Public.
4. Нажми Create repository.
5. На странице репозитория выбери Add file -> Upload files.
6. Загрузи index.html (README.txt тоже можно загрузить) и нажми Commit changes.
7. Открой Settings -> Pages.
8. В разделе Build and deployment выбери Deploy from a branch.
9. В Branch выбери main и папку /(root), затем Save.
10. Подожди пару минут. На странице Pages появится ссылка вида https://ТВОЙ-НИК.github.io/dagestan-travel/ .

Фотографии:
Сайт загружает реальные фотографии с Wikimedia Commons. Для показа изображений нужно интернет-соединение. Внизу страницы есть раздел с источниками изображений. Условия лицензии могут отличаться у разных фотографий; если будешь повторно использовать фото в другом проекте, проверь автора и лицензию на странице источника.

Если какое-то изображение не загрузилось, сайт пытается показать запасную фотографию Дагестана.
