ДАГЕСТАН — МЕЖДУ НЕБОМ И КАМНЕМ

Одностраничный путеводитель по десяти туристическим местам Дагестана. Для каждой точки есть короткий рассказ, исторический контекст, интересный факт и объяснение, чем она важна.

Файлы:
- index.html — сайт (HTML, CSS и JavaScript в одном файле).
- .github/workflows/pages.yml — публикация сайта через GitHub Pages.

Сайт: https://saneck201-cpu.github.io/dagestan_travel/
Исходный код: https://github.com/saneck201-cpu/dagestan_travel

Публикация:
GitHub Pages автоматически разворачивает сайт после изменений в ветке main. Чтобы проверить ход публикации, открой вкладку Actions в репозитории. При первой настройке может потребоваться выбрать GitHub Actions в Settings → Pages → Build and deployment → Source.

Фотографии загружаются с Wikimedia Commons. Ссылки на страницы изображений находятся внизу сайта. Для показа фотографий, карты и внешних библиотек требуется интернет-соединение.
